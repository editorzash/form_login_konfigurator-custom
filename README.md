# Form Login — POS STUDIO Cloud POS

Halaman portal autentikasi & login resmi untuk **POS STUDIO** (Customizer & Preview Engine).

## Fitur Utama Form Login
1. **Dua Mode Autentikasi**:
   - Mode 1: **Email & Kata Sandi** (dengan fitur intip kata sandi).
   - Mode 2: **PIN Cepat Kasir (6-Digit)** dengan visual dots & virtual numeric keypad layar sentuh.
2. **Akun Demonstrasi 1-Klik**:
   - 👑 **Super Admin / Owner**: `designer@posbuilder.id` (PIN: `112233`)
   - 💼 **Manajer Operasional**: `pm@posbuilder.id` (PIN: `445566`)
   - 💳 **Kasir Shift**: `tester@posbuilder.id` (PIN: `123456`)
3. **Pemilihan Cabang / Outlet Aktif** (Studio Workspace, Client Sandbox, Production Preview).
4. **Indikator Live Status**: Menampilkan status konektivitas server secara interaktif.
5. **Auto Redirect**: Setelah autentikasi berhasil, pengguna langsung diarahkan ke aplikasi utama di [`../konfigurator-custom/index.html`](../konfigurator-custom/index.html).
6. **Bypass Button**: Tombol shortcut untuk penguji/developer membuka aplikasi tanpa proses login.

## Menjalankan Halaman
Cukup buka file `index.html` langsung di browser Anda (atau via server lokal / GitHub Pages).
